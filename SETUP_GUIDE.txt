📋 SETUP STEPS

1. CREATE .env FILE

Copy .env.example → .env and configure:

  OWNER_ID=YOUR_TELEGRAM_ID,OTHER_OWNER_ID
  ADMIN_ID=ADMIN_TELEGRAM_ID,ANOTHER_ADMIN_ID

Examples:
  OWNER_ID=123456789,987654321
  ADMIN_ID=111111111,222222222

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. INSTALL & RUN

  npm install
  npm start

📊 COMMAND PERMISSIONS

QUICK ACTIONS (All users):
  /start /pair /unpair /ping /runtime /stats /report /tutorial /help

ADMIN CONTROL (Admin + Owner):
  /users /listpair /broadcast /clean /ban /unban 
  /checkuser /maintenance /logs /announce

OWNER ONLY:
  /addadmin /removeadmin /restart

⚡ WHATSAPP FEATURES

Antidelete:
  †antidelete on  — Enable message restoration
  †antidelete off — Disable

DMBlocker (Owner only):
  †dmblock on  — Block strangers
  †dmblock off — Disable

Permit (Owner only):
  †permit @user        — Unblock user
  †permit [number]     — Unblock by number

Banish:
  †banish @user        — Permanent ban
  †banish [number]     — Ban by number
